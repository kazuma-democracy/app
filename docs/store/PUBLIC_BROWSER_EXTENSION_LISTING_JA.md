# WA Commons Browser Extension v0.1 — Store Listing (ja)

## Name

WA Commons 企業チェック

## Short description

企業の公開Evidenceを確認し、自分で選んだ方針に沿って軍事・防衛関連の情報を見られるブラウザ拡張です。

## Description

WA Commons 企業チェックは、日本の上場企業について、公開情報に基づくEvidenceとその出典を確認するためのブラウザ拡張です。

v0.1では、軍事・防衛関連の公開Evidenceを中心に表示します。表示はWA Commonsが会社を一律に「良い・悪い」と判定するものではありません。ユーザーが選択した方針に対して、確認できたEvidenceと不明・未解決・未統合の状態を区別して表示します。

「NONE」は安全・問題なし・推奨を意味しません。現在の公開Evidenceと選択した方針ではEXCLUDE/WATCHに該当しなかった、という限定的な状態です。

企業検索は会社名または証券コードから行えます。現在ページから候補を探す機能は、ユーザーがボタンを押した時だけ一時的にページ上の選択文字またはタイトルを読み取ります。ページ情報だけで企業を自動確定することはありません。

v0.1は閲覧履歴、Cookie、ページ内容、検索履歴をWA Commonsサーバーへ送信しません。テレメトリや広告トラッカーもありません。選択した方針のみをブラウザ内に保存します。

## Important limitation

WA Commonsは、表示された情報が企業の全活動を網羅しているとは主張しません。情報が見つからないこと、不明であること、未統合であることは、当該企業に問題がないことを意味しません。
